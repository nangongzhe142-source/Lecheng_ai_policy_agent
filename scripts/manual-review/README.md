# Manual Review Queue Scripts

This folder provides a minimal "2 + 1" operational implementation:

- **2 (realtime):** Dify Chatflow pushes manual-review-required records to your queue API.
- **1 (batch):** Daily/weekly export reconciliation catches missed records.

## 1) Filter manual review records from Dify export

Use `filter_manual_review.py` to parse `.jsonl.gz` from `export-app-messages`.

### Input expected

- Dify exported file generated by:

```bash
flask export-app-messages --app-id <APP_ID> --end-before <YYYY-MM-DD> --filename <base-name>
```

### Example

```bash
python scripts/manual-review/filter_manual_review.py \
  --input exports/daily_2026-06-01.jsonl.gz \
  --output-csv outputs/manual_review_export_2026-06-01.csv
```

### Optional: push records to queue API

```bash
python scripts/manual-review/filter_manual_review.py \
  --input exports/daily_2026-06-01.jsonl.gz \
  --output-csv outputs/manual_review_export_2026-06-01.csv \
  --queue-api-url "https://example.com/review-queue" \
  --queue-api-token "YOUR_TOKEN"
```

The script detects manual review records using:

1. Preferred machine-readable line:
   - `REVIEW_JSON={"need_manual_review":true,...}`
2. Fallback regex for:
   - `是否需要人工复核：是`

## 2) Reconcile realtime queue and batch records

Use `reconcile_manual_review.py` to compare:

- Realtime queue export (`ingress=webhook`)
- Batch filtered export (`ingress=export_reconcile`)

### Example

```bash
python scripts/manual-review/reconcile_manual_review.py \
  --realtime-csv outputs/realtime_queue_2026-06-01.csv \
  --batch-csv outputs/manual_review_export_2026-06-01.csv \
  --output-csv outputs/reconcile_2026-06-01.csv
```

Output action values:

- `missing_in_realtime`
- `extra_in_realtime`
- `consistent`

## 3) LangSmith sync (verified Dify output shape)

Dify traces in LangSmith use this structure (not `text` / `answer`):

```json
{
  "choices": {
    "content": "<full assistant answer including 回答评估>",
    "role": "ai"
  }
}
```

User query is in:

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "用户问题"}
  ]
}
```

### Inspect structure

```bash
set LANGSMITH_API_KEY=your_key
python scripts/manual-review/inspect_langsmith_structure.py
```

### Sync manual-review runs to CSV (and optional queue API)

```bash
set LANGSMITH_API_KEY=your_key
python scripts/manual-review/sync_langsmith_manual_review.py ^
  --project Lecheng_policy_ai_agent ^
  --run-name llm ^
  --limit 200 ^
  --output-csv outputs/langsmith_manual_review.csv
```

Use `--hours 24` to only scan recent runs.

## 4) LangSmith Annotation Queue auto-sync (recommended)

Push runs that need manual review directly into a LangSmith **Annotation Queue** (web UI todo list).

### Get parameters

| Parameter | Where |
|-----------|--------|
| `LANGSMITH_API_KEY` | LangSmith → Settings → API Keys → create and copy once |
| Project name | Dify tracing project, e.g. `Lecheng_policy_ai_agent` |
| Queue ID | LangSmith → Annotation Queues → open your queue → UUID in URL (`.../queues/<QUEUE_ID>`) |

### Output field (do not use `text` / `answer`)

Dify stores the assistant reply at:

```text
run.outputs["choices"]["content"]
```

The script uses [`review_common.py`](review_common.py) to parse `REVIEW_JSON=...` or `是否需要人工复核：是`.

### Dry-run first

```powershell
cd "d:\LECHENG POLICY AI AGENT\scripts\manual-review"
$env:LANGSMITH_API_KEY="your_key"
python sync_langsmith_annotation_queue.py `
  --queue-id "YOUR_QUEUE_UUID" `
  --project Lecheng_policy_ai_agent `
  --run-name llm `
  --hours 24 `
  --limit 500 `
  --dry-run
```

### Push to annotation queue

```powershell
python sync_langsmith_annotation_queue.py `
  --queue-id "YOUR_QUEUE_UUID" `
  --project Lecheng_policy_ai_agent `
  --run-name llm `
  --hours 24 `
  --limit 500
```

- Prefers `llm` runs (avoids duplicate `message` + `llm` pairs).
- Skips runs already in the queue (prefetch + duplicate API errors).
- Optional `--root-only` scans root runs only (not recommended for Dify).

### Daily automatic sync (Windows, recommended)

One-time setup in PowerShell (as your Windows user):

```powershell
cd "d:\LECHENG POLICY AI AGENT\scripts\manual-review"
Copy-Item langsmith.env.example langsmith.env.local
# Edit langsmith.env.local: set LANGSMITH_API_KEY (and queue/project if needed)

.\run_annotation_sync_daily.ps1          # test once
.\register_daily_annotation_sync_task.ps1  # register task, default 08:00 daily
```

| File | Purpose |
|------|---------|
| `langsmith.env.example` | Safe template (commit to git) |
| `langsmith.env.local` | Your API key (gitignored) |
| `run_annotation_sync_daily.ps1` | Runner: loads env, syncs last 30h, writes `logs/` |
| `register_daily_annotation_sync_task.ps1` | Creates task `Lecheng-LangSmith-ManualReview-Sync` |

Customize schedule: `.\register_daily_annotation_sync_task.ps1 -Time "07:30"`

Logs: `scripts/manual-review/logs/annotation_sync_*.log` (last 60 files kept).

Default scan window is **30 hours** (`SYNC_HOURS` in env file) so a once-daily job still catches late-night runs. Runs already in the queue are skipped (idempotent).

### Manual Windows Task Scheduler

If you prefer the GUI: trigger **Daily**, action **powershell.exe** with arguments:

```text
-NoProfile -ExecutionPolicy Bypass -File "d:\LECHENG POLICY AI AGENT\scripts\manual-review\run_annotation_sync_daily.ps1"
```

Start in: `d:\LECHENG POLICY AI AGENT\scripts\manual-review`. Use `langsmith.env.local` for the API key (do not paste keys into the task dialog).

## 5) Suggested daily workflow

1. Export Dify app messages.
2. Run `filter_manual_review.py`.
3. (Optional) POST filtered rows to queue API.
4. Export realtime queue csv (from your queue storage).
5. Run `reconcile_manual_review.py`.
6. Review rows tagged `missing_in_realtime` and `extra_in_realtime`.
7. Open LangSmith → Annotation Queues for human review and gold answers.
